qmutfind

Find the mutations in one fungal genome sample.

Style

qmutfind maps sequencing reads to a reference genome, finds SNPs and small insertions and deletions, says what each change does to the genes, and draws the result.

It runs in this page. The page does not send your files to any server. Use it for one haploid sample, for example an evolved Aspergillus fumigatus strain that you compare with its reference.

  1. Choose a reference genome (FASTA).
  2. Choose the reads (FASTQ). Add a gene file (GFF3) to get gene effects.
  3. Run. The page maps the reads and calls the variants.
  4. Read the VCF, the statistics and the picture of the region.

What has been measured

  • The browser build gives the same VCF as the command-line tool. This was checked byte for byte on a real sample (EVOL20_3, 2,854,974 reads). In headless Firefox it took 64 seconds and about 1.5 GB of memory.
  • On simulated reads, short reads at 20x or more found about 99% of SNPs and 97.5% of small indels, with precision of 98.5% or higher. Nanopore reads at 24x found 99.6% of SNPs and 94.8% of small indels.
  • The numbers come from five held-out simulated data sets that were not used to set the thresholds.

Limits

  • The accuracy numbers above are from simulated reads. Real reads contain repeats and errors that the simulators do not model. There is no real-data truth set yet.
  • Below about 10x coverage, the default depth rule misses many variants (about half at 5x).
  • Short reads cannot show large insertions. Large indels are called from long reads only.
  • In the browser, a read pair is mapped as two separate reads. The command-line tool can map pairs.
  • Only Firefox was tested. Chrome and Safari were not. Large data sets need several GB of memory.
  • The tool is for one haploid sample. It is not a diploid or population caller.
  • The gene effects use one transcript per gene (the one with the longest coding sequence).

Command line

The same code runs as a command-line tool. It can also fetch FungiDB genomes with your own API key.

qmutfind call --reference ref.fa.gz --reads r1.fastq.gz --reads2 r2.fastq.gz \
              --sample mutant1 --preset short --out mutant1.vcf
qmutfind annotate --vcf mutant1.vcf --reference ref.fa.gz --gff genes.gff3.gz --out mutant1.annot.vcf
