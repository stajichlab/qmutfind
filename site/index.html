qmutfind

Find the mutations in one fungal genome sample.

Style

qmutfind maps sequencing reads to a reference genome, finds SNPs and small insertions and deletions, says what each change does to the genes, and draws the result.

It runs in this page. The page does not send your files to any server. Use it for one haploid sample, such as a fungal isolate or an evolved strain, compared with a reference genome.

  1. Call. Map the reads and call the variants. This gives a VCF.
  2. Summarize. Count the variants and plot where they are along the genome.
  3. Draw. Add gene effects, pick a variant from the list, and see it in its gene.

Each step keeps its result in this page, and the next step uses it. You can also start at step 2 or 3 with a VCF file from another tool.

How it works

  • Mapping. Reads are mapped to the reference in WebAssembly, with the Rust aligner rammap (short-read and Nanopore presets).
  • Calling. A built-in haploid caller counts bases at each position and reports SNPs and indels that pass depth, allele-fraction and mapping-quality rules. Long reads can also give large indels (50 bp or more).
  • Effects. Each variant is judged on the transcript with the longest coding sequence of its gene. Introns and UTRs are worked out from the exons and the coding sequence.
  • Output. A VCF, a statistics table (JSON), a genome-wide SVG plot and a locus page for each variant you draw.

Limits

  • Accuracy was measured on simulated reads, which are cleaner than real reads. Repeats and systematic errors in real data can give false calls. Check important variants by eye or with a second method. Results are on the project page.
  • At low coverage (below about 10x) the default depth rule misses many variants.
  • Short reads cannot show large insertions. Large indels are called from long reads only.
  • In the browser, a read pair is mapped as two separate reads. The command-line tool can map pairs.
  • Only Firefox was tested. Chrome and Safari were not. Large data sets need several GB of memory.
  • The tool is for one haploid sample. It is not a diploid or population caller.
  • Gene effects use one transcript per gene (the one with the longest coding sequence).

Command line

The same code runs as a command-line tool. It can also fetch FungiDB genomes with your own API key.

qmutfind call --reference ref.fa.gz --reads r1.fastq.gz --reads2 r2.fastq.gz \
              --sample mutant1 --preset short --out mutant1.vcf
qmutfind annotate --vcf mutant1.vcf --reference ref.fa.gz --gff genes.gff3.gz --out mutant1.annot.vcf
