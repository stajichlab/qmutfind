This project is designed to try to do quick read mapping to find mutations based on FastQ Illumina sequencing or possibly long-read Nanopore sequencing/PacBio.

The input data would be compressed FastQ or long-read FastQ, uploaded through a WASM interface to process the data, align it to a genome, and identify mutations. We would see how those mutations overlap with annotated genes and give a genome browser view of where the mutations are, using either a setup like JBrowse (where the data could be projected) or a static view of the mutations.

We also want to classify the mutations as to whether or not they show up as synonymous or non-synonymous if they're insertions and deletions. To run this typically on Unix, we would use BWA or minimap. I'm not sure if this would work perfectly in WASM, but I think we can do it in a low-memory environment, and we would pre-load genomes. Or we can have genomes be imported from NCBI or FungiDB or uploaded by the user, along with a GFF file that lists where the genes are. If it's a properly formatted GFF with coding sequence, then we can identify synonymous and non-synonymous, and if there are UTRs, we can also identify that.
